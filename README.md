# Personal homepage

Source of <https://Jay-Jiayu-Chen.github.io/>.

Plain HTML, CSS and a few lines of JavaScript — no build step and no
dependencies. To preview locally:

```sh
python -m http.server 8000
```

then open <http://localhost:8000>.

## Files

```
index.html    page content
styles.css    styling
scripts.js    section fade-in
images/       profile photo
assets/       CV PDF (compiled on Overleaf)
```

The CV PDF is generated from LaTeX on Overleaf; `assets/CV_Jiayu_Chen.pdf`
is the compiled output.
